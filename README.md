## ⚖️ Legal-Ease AI: Enterprise Document RAG Explorer

Legal-Ease AI is an end-to-end, production-grade Full-Stack **Retrieval-Augmented Generation (RAG)** application. It is designed to ingest complex, unstructured legal and financial PDF documents, convert their contents into high-dimensional vector embeddings, and store them securely inside a local persistent vector database. 

By pulling context directly from documents dynamically based on user questions, the system solves the critical industry challenge of Large Language Model (LLM) factual hallucinations. It acts as an "open-book exam" for the AI, ensuring that answers generated by the local open-source transformer model remain 100% accurate and strictly bounded by the uploaded source materials. 

This repository serves as a comprehensive portfolio piece demonstrating the intersection of **Core Machine Learning Engineering** (matrix mathematics, semantic vector embeddings, hardware-isolated fallback architectures) and **AI Application Development** (asynchronous FastAPI endpoints, decoupled multi-terminal microservice routing, and stateful Streamlit dashboard user interfaces).
